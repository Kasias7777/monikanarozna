# Monika Narożna - strona internetowa

Responsywna strona React dla marki Monika Narożna.

## Uruchomienie lokalne

Wymagane: Node.js 20+ oraz pnpm.

```bash
pnpm install
pnpm dev
```

Następnie otwórz adres wyświetlony przez Vite, zwykle `http://localhost:3000`.

## Build produkcyjny

```bash
pnpm build
```

Gotowe pliki znajdą się w katalogu `dist/`.

## Ważne dane do uzupełnienia

Przed publikacją warto uzupełnić lokalizację, politykę prywatności oraz ewentualny system obsługi formularza kontaktowego. Aktualnie formularz przygotowuje wiadomość w aplikacji pocztowej.
